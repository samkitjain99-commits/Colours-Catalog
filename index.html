☁️ Cloud sync (Firebase)

Keep a copy of everything in your own Firebase project, and bring it to another phone or browser by signing in with the same account.

1. One-time setup (about 5 minutes)
  1. Go to console.firebase.google.com → Add project (free Spark plan is enough).
  2. Build → Authentication → Get started → enable Email/Password.
  3. Build → Firestore Database → Create database. Then open the Rules tab, paste the rules below and Publish.
  4. Project settings (gear) → Your apps → add a Web app (</>) → copy the firebaseConfig block and paste it below.
  5. Authentication → Settings → Authorised domains → add colours-catalog.vercel.app.
